# Lumi Local illustration set

Original local SVG artwork, added October 2026. No remote image service,
generated customer screenshots, or third-party illustration package is used.

All drawings use the Lumi Local palette: Civic Navy outlines, Lumi Blue,
warm Paper, opaque White, and small Amber accents. There are no embedded
fonts, scripts, animations, external references, or business-performance data.

| Placement | Files under `public/illustrations/` |
| --- | --- |
| Illustrative industry concepts | `salon.svg`, `garage.svg`, `hvac.svg` |
| Included services | `website.svg`, `contact.svg`, `map.svg`, `review.svg`, `hosting.svg`, `alerts.svg` |
| Delivery steps | `brief.svg`, `approve.svg`, `publish.svg` |
| Enquiry section | `welcome.svg` |

The same drawings are used on Vietnamese and English pages. They contain no
visible text; surrounding HTML supplies the localized explanation. Images
use empty alt text because they accompany that explanation, and intrinsic
dimensions reserve their space before loading. All are lazy loaded.

The review stand is a conceptual drawing, not a functional review QR.
The alerts drawing does not change the existing "where implemented" condition.
Industry drawings remain beside the explicit illustrative-concept notice.
